banners

Composable slides for marimo presentations.

Every slide is drawn on a fixed 16:9 canvas by a Template, which combines layouts with a Palette (colors) and a Theme (fonts, title weight, icon stroke, scale). A palette or theme can also be declared on its own and replaces the template's one.

from banners import BLUE, TERRA, Closing, Cover, Section, Text, configure

configure(template=TERRA, palette=BLUE, team="Analytics", date="November 2026")

Cover(title="My Project", subtitle="Context in one line.")
Section(title="Results", content=[Text("**Point 1** — Concrete result."), Text("**Point 2** — Team impact.")])
Closing(title="Thank you")

Three input formats are supported:

Flat list -- linear chain::

FlowAnimation(["S3", "Glue", "Athena"])

FlowAnimation([
    {"name": "S3",   "detail": "raw data"},
    {"name": "Glue", "detail": "ETL job"},
])

Nested list -- multi-row layered layout (each outer item is a layer; every node in layer i connects to every node in layer i+1)::

FlowAnimation([
    ["Ingest"],
    [{"name": "Transform A", "detail": "features"},
     {"name": "Transform B", "detail": "filters"}],
    ["Load"],
])

Explicit graph -- arbitrary connections via edges::

FlowAnimation(

    edges=[

)

195    def _on(self, bg: str, color: str) -> str:
196        """Return `color`, or a readable fallback when it lacks contrast with `bg`.
197
198        The check uses the WCAG contrast ratio with a 3:1 minimum, the threshold
199        for large text. It does nothing when `auto_contrast` is off or when
200        either color cannot be parsed.
201
202        Args:
203            bg: CSS color of the background the text or icon sits on.
204            color: CSS color wanted for the text or icon.

206        Returns:
207            `color` when it is readable on `bg`; otherwise `on_dark` for dark
208            backgrounds and `text` for light ones.
209        """
210        from .background import _parse_first_color, _relative_luminance
211
212        if not self.auto_contrast:
213            return color
214        a, b = _parse_first_color(bg), _parse_first_color(color)
215        if a is None or b is None:
216            return color
217        la, lb = _relative_luminance(*a), _relative_luminance(*b)
218        ratio = (max(la, lb) + 0.05) / (min(la, lb) + 0.05)
219        if ratio >= 3:
220            return color
221        return self.palette.on_dark if la < 0.18 else self.palette.text
