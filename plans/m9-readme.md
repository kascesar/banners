# M9 — Short, striking README: Implementation Plan

> **For agentic workers:** execute with superpowers:executing-plans (inline, as
> `CLAUDE.md` requires). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A README of at most 120 lines that shows off banners with a 2×3
template gallery and three showcase GIFs, all generated by `make readme-images`.

**Architecture:** `scripts/readme_images.py` renders slides to PNG in headless
Chromium (Playwright). The template gallery is built in Python (one `Section`
per template, wrapped in a plain HTML page). The showcase GIFs come from
`marimo export html example/showcase.py`: the script walks the exported page in
document order, splits the slide canvases into parts at the part-title videos,
screenshots each canvas and joins each part into a GIF with Pillow, one frame
per slide (so there are no blended frames). Images go to `media/`.

**Tech Stack:** Python ≥ 3.11, Playwright (Chromium), Pillow (already installed
with matplotlib), marimo export, pytest.

**Spec:** `MILESTONES.md` → "M9 — Short, striking README".

## Global Constraints

- `README.md` at most 120 lines; no API reference.
- Gallery templates, in this order: `Template()`, `EXECUTIVE`, `INSTITUTIONAL`, `COSMOS`, `VIBRANT`, `TERRA`. `BECH` never appears.
- About 1.5 s per slide (`duration=1500` ms), loop forever, hard cuts.
- Image URLs in the README: `https://raw.githubusercontent.com/kascesar/banners/main/media/<file>`.
- No organization brand assets in the README or `media/`.
- Everything in English; commits per task on `milestone/m9-readme`, Conventional Commits, no `Co-Authored-By`.
- Verification for every task: `make check`.

## Review Focus

1. A README code block that needs an optional extra (pandas, manim) fails in CI, which installs only core + pandas + plotly: the README test runs every block, so only core and pandas may be used (Task 2 test).
2. The exported showcase has a part title video that fails to render: the parts would merge. `group_by_part` is tested with that input (Task 1).
3. A GIF frame count different from the slide count would mean blended or dropped frames (Task 1 test on `make_gif`).
4. The README grows past 120 lines in later edits (Task 2 test).
5. The removed root GIFs are still referenced somewhere (Task 2 step: `git grep demo-` returns nothing).
